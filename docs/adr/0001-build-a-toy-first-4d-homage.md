# Build a toy-first 4D homage

We will build a recognizable browser homage to 4D Toys, not an exact remake and not a generic 4D visualization. The first complete version should prioritize playful manipulation of 4D toys, hybrid direct/tool-based controls, 4D-ish consistency, and micro-prompts that help players understand what changed without turning the experience into a lesson.

**Considered Options**

- A math-first visualization would make the dimensional model explicit, but it risks missing the original game's playful discovery.
- A vibe-first room would be faster to polish, but it risks becoming a 3D toybox with 4D-themed labels.
- A full 4D rigid-body simulation would be impressive, but it would spend the project budget on physics fidelity before the browser experience proves fun.

**Consequences**

The implementation should be judged by whether users can grab, slice, rotate, toss, and compare changing visible slices of 4D toys. Build checks alone are not enough evidence; browser interaction checks must verify that the toy loop actually works.
